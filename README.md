# Sridurgesh Ravichandran — Personal Research Desktop

A personal website inspired by vintage desktop interfaces, with pixel illustrations of RNA, proteins, atomic lattices, and electron microscopy.

Public website: https://sridurgesh007.github.io/

## Hosting

This is a static website. GitHub Pages publishes the root directory of the `main` branch. The `.nojekyll` file disables Jekyll processing. No package installation or build step is required.

## Updating the website

- `index.html`: introduction, research interests, project cards, and selected publications.
- `app.js`: contact destinations, project dialogs, résumé link, and canvas illustrations.
- `style.css`: colours, layout, retro controls, and responsive styling.
- `assets/sridurgesh-ravichandran-resume.pdf`: current résumé. Replace this file to update the PDF while retaining its existing links.

Open `index.html` in a browser to preview the website locally. For GitHub-hosted changes, commit updates to `main` and wait for the Pages deployment to complete.

The scientific graphics are stylised illustrations. Protein and RNA thesis work and the consumer-hardware deep research framework are described as work in progress.
